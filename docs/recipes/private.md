# Recipe: 自分だけの予定・日記（チャットで直す）

旅のしおりの「自分の日記」の欄にある「チャットで直す」でコピーした文の先頭に付く、直し方の説明。
コピーした文には、この説明の後ろに **「旅行」「共有の予定（参照）」「自分の予定・日記」** が付いている。
チャットはこの説明に従い、利用者が頼んだとおりに「自分の予定・日記」を直して返す。

## 頼みの受け方

文の最初に **「直してほしいこと」** があれば、それが利用者の頼み。無ければ、利用者がチャットで続けて書く頼みに従う（頼みが来るまで返事の JSON を返さず、何を直すか聞く）。

- **利用者が頼んだところだけ**直す。頼まれていない予定・日記・文言は変えない
- 「共有の予定（参照）」は、自分の予定を共有の予定の間に置くための参考。**直しても反映されない**。返事に入れない
- 本名・予約番号・パスワード・チケットの QR などは書かない

## 返す形

返すのは、次の形の JSON を **1 つだけ**。コードフェンス（```` ```json ````）で囲み、前後に説明の文を付けてもよい。途中で切らず、最後まで返す。

```
{ "schemaVersion": 1, "entries": [ … ] }
```

- `entries` は、**直したあとの自分の予定・日記の全部**。直したところだけを返さない
- 残す項目と直す項目は、今の `id` をそのまま書く。新しい項目は `id` を書かない（しおりの側が付ける）。消したい項目は `entries` から外す
- 1 人 100 件まで

各項目の形（ほかの項目は足さない）:

| 項目 | 必須 | 中身 |
|---|---|---|
| `id` | 今ある項目だけ | 今の値をそのまま |
| `kind` | 必須 | `item`（予定）か `diary`（日記） |
| `day` | 必須 | `YYYY-MM-DD`。旅行期間の中の日 |
| `startsAt` | 予定は必須、日記は書かない | 時差つきの日時（例 `2026-11-21T10:30:00+09:00`）。「旅行」の時間帯で、`day` と同じ日 |
| `endsAt` | 任意（予定だけ） | 時差つきの日時。`startsAt` より後 |
| `title` | 予定は必須 | 160 字まで。日記は空でもよい（`""`） |
| `body` | 日記は必須 | 4000 字まで。予定は空でもよい（`""`） |
| `place` | 任意 | `{ "label": "場所の名前", "publicUrl": "https://…" }`。`publicUrl` は任意で、公開の HTTPS の URL だけ |

## 報告

JSON のあとに、何を足した・直した・消したかを短く書く。利用者はその返事をしおりに貼り、今の予定・日記との差分を見てから反映する。
